# File Manager

A lightweight, retro-styled file manager that runs entirely on GitHub Pages — no backend required.

## Overview

This project provides a simple terminal-inspired interface for browsing and downloading files. It uses client-side authentication and a JSON-based file tree, making it easy to deploy as a static site.

## Features

- ️ Retro terminal-style dark UI
-  Client-side login with configurable accounts
-  Folder navigation with breadcrumb support
-  File viewing and downloading
-  No server or database needed
-  One-click deployment to GitHub Pages
